# Project Review

## Addressing Relevant Implications

### End-User Implications of Digital Technologies

The way i addressed this implement was to put clear routes like /group/id which will help the user know where he is. I have made it so that the user must login to do certian stuff in my website like creating a group or just joining one while also adding flash messages which clearly states whether a user has created a group or joined even when leaving it. 
In short i addressed common issues people will encounter in my website amd i used that knowledge to make my website feel smooth and easily navigatable.


### Aesthetic Implications of Digital Technologies

During the development of my project, I focused on creating a clean, and user-friendly design to improve the aesthetic appeal of the system. I used separate Jinja templates to maintain a clear layout and ensure that each page followed a similar visual structure. This helped create a consistent theme throughout the website making it easier for users to understand and navigate.


### Usability Implications of Digital Technologies

During the project, I focused on making the system easy to use for my end users. The website features a clear navigation flow with pages for signing up, logging in, joining groups, creating groups, and managing tasks. Flash messages are used to provide feedback to users, letting them know whether actions such as logging in, creating a group, or joining a task were successful.


### Functionality Implications of Digital Technologies
The system was built with several functional features that allow users to interact effectively and achieve their goals. Users can create groups, join existing groups with a passkey, and add tasks within these groups, which are then displayed for all members to see


### Accessibility Implications of Digital Technologies

Accessibility was considered to make the system usable by a wider range of users. Forms and input fields are clearly labeled, pages use simple layouts for readability, and navigation is consistent across the site. Flash messages and prompts provide clear feedback for users who may have difficulty seeing.

## Overall Review

Overall, the project went well and achieved its main goal of letting users create groups, add tasks, and work together.

What went well: The main features, like creating and joining groups, adding tasks, and showing group info, worked as expected. Login and registration were secure, and flash messages helped users know what was happening.

What didn’t go so well: The website could look nicer and be easier to use for first-time users. Some errors, like duplicate groups or wrong passkeys, were tricky at times.

Impact of testing/trialling: Testing helped find bugs and improve error messages. It also showed where the interface could be more clear and simple for users.

What I would do differently: Next time, I would make the website look more attractive, add tips for users, and include features like searching or filtering tasks and groups to make it easier to use.
